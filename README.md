# NackSgro — Official Website

A minimal, one-page static artist website designed for GitHub Pages.

## Files

- `index.html` — complete one-page website
- `assets/nacksgro.jpg` — supplied artist portrait

## Publish on GitHub Pages

1. Create a **public** GitHub repository. Recommended repository name:
   `nacksgro.github.io` if your GitHub username is `nacksgro`.
2. Upload `index.html` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under the publishing source, choose the `main` branch and `/ (root)`.
5. Save and open the GitHub Pages URL.

If your GitHub username is not `nacksgro`, use:
`https://YOUR-USERNAME.github.io/`

## Important

The TikTok button currently points to:
`https://www.tiktok.com/@NackSgro`

If the real TikTok username is different, replace that URL in `index.html`.

## Google / Knowledge Panel

The page already includes:
- clear artist name and description
- `ProfilePage` + `Person` JSON-LD
- `sameAs` links for Spotify, Apple Music and YouTube
- artist image metadata
- mobile responsive layout
- Open Graph metadata

A Knowledge Panel cannot be guaranteed by code alone. After publishing, verify the site in Google Search Console and keep the artist name, image, bio and official links consistent across platforms.
